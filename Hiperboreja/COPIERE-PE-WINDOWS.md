# Copiere pe Windows → D:\Hiperboreja

Acest folder **este** arhiva. Pe calculatorul tău Windows:

1. Descarcă ZIP-ul `Hiperboreja.zip` (din artifacte / din repository).
2. Extrage totul în `D:\Hiperboreja`.
3. Deschide `D:\Hiperboreja\preview\index.html` în browser ca să vezi catalogul.

Nu pot scrie direct pe discul D: din acest mediu cloud. După descărcare, calea trebuie să fie exact:

`D:\Hiperboreja\ANALIZA.md`
`D:\Hiperboreja\content\covers\`
`D:\Hiperboreja\content\images\`
`D:\Hiperboreja\content\books\`
`D:\Hiperboreja\content\blog\`

Mâine schițăm site-ul nou din aceste fișiere.
