# Dosarul Interpol — bază de lucru (schelet)

Acest folder ține **faptele pe caz**, nu biografiile personajelor.

Completează fișierele pe măsură ce ai documente. Personajele citesc de aici.

## Fișiere

| Fișier | Rol |
|--------|-----|
| `ACTORI.md` | persoane & companii |
| `TIMELINE.md` | cronologie evenimente |
| `CONTRADICTII-MOVILA.md` | exemplu de lucru Irina (schelet) |
| `SURSE.md` | index documente |

## Reguli

1. Fiecare afirmație importantă → sursă (dosar, pagină, dată).
2. Dacă nu ai documentul → scrie `[LIPSĂ]`, nu completa din memorie.
3. Separă: eveniment / declarație / interpretare.
