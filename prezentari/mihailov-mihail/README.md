# Mihailov Mihail — prezentare de caracter

Prezentare vizuală (HTML) despre **Mihailov Mihail**, fratele Verei Țurcanu: cine e, ce a semnat, ce a cumpărat, ce a cerut instanței, ce a spus, ce arată actele.

Limbă: română simplă. Data: **04.09.2026**.  
Nu e sentință. Nu înlocuiește avocatul.

## Cum deschizi

Deschide `index.html` în browser **sau** pornește un server local:

```bash
cd prezentari/mihailov-mihail
python3 -m http.server 8765
```

Apoi: [http://127.0.0.1:8765/](http://127.0.0.1:8765/)

## Navigare

- Săgeți stânga / dreapta, `Space`, `PageUp` / `PageDown`
- Click pe săgețile de pe ecran sau pe punctele din dreapta
- `Home` / `End` — prima / ultima pagină
- `P` — mod print (toate ecranele, pentru PDF)
